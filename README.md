# AI-Steward
AI-Steward: Survival Kit for Claude Code Users
Have you also been hit by the "Rate Limit Wall"? AI-Steward is a lightweight control panel that helps you seamlessly switch between AI agents (Claude, Gemini, Aider) when you run out of credits or the wait time gets too long.

✨ Features
Agent Switcher: Jump between Claude and Gemini while maintaining context via CLAUDE.md.

Smart Handover: Automatically copies a summary prompt to the clipboard for quick handover.

AI-Sentry: A built-in timer that monitors your Rate Limits and beeps when you can start coding again.

Dark Mode UI: A stylish Tkinter panel that always stays on top of the screen.

🛠 Installation
Requirements: Python 3.12+ and VS Code.

Clone: ​​git clone https://github.com/YOUR_USERNAME/AI-Steward.git

API Key: Add your GEMINI_API_KEY to your environment variables.

Run: Use the provided .bat file to launch the panel with one click.
